# 🌾 项目文件清单 | Project Files Overview

## 📁 项目结构

```
rice_demo/
├── app.py                      # Flask 后端主程序
├── requirements.txt            # Python 依赖包列表
├── run_app.bat                 # Windows 启动脚本
├── config_example.py           # 配置示例文件
├── .gitignore                  # Git 忽略文件
│
├── README.md                   # 项目说明文档
├── QUICKSTART.md              # 快速开始指南
├── SUGGESTIONS.md             # 改进建议文档
│
├── templates/                  # HTML 模板文件夹
│   └── index.html             # 主页面模板
│
├── static/                     # 静态资源文件夹
│   ├── css/
│   │   └── styles.css         # 样式文件（水稻主题）
│   └── js/
│       └── script.js          # JavaScript 交互脚本
│
└── uploads/                    # 上传文件临时存储
    └── .gitkeep               # 占位文件
```

## 📄 文件说明

### 核心文件

#### 1. `app.py`
- **功能**：Flask Web 应用主程序
- **包含**：
  - 模型初始化
  - 图片上传处理
  - 文件夹加载
  - 推理预测
  - API 接口
- **大小**：~8KB
- **语言**：Python

#### 2. `requirements.txt`
- **功能**：项目依赖包列表
- **包含**：
  - Flask 2.3.2
  - Pillow 9.5.0
  - NumPy
  - PaddlePaddle
- **用途**：使用 `pip install -r requirements.txt` 安装依赖

#### 3. `run_app.bat`
- **功能**：Windows 快速启动脚本
- **特点**：
  - 自动检查 Python 环境
  - 验证配置文件和权重文件
  - 简化启动流程
- **使用**：双击运行即可

### 前端文件

#### 4. `templates/index.html`
- **功能**：主页面 HTML 模板
- **特点**：
  - 水稻主题设计
  - 动态背景动画
  - 响应式布局
  - 中英文双语界面
- **大小**：~6KB

#### 5. `static/css/styles.css`
- **功能**：网页样式文件
- **特点**：
  - 水稻配色（绿色、金色）
  - 现代化设计
  - 动画效果
  - 移动端适配
- **大小**：~12KB
- **主题色**：
  - 主绿色：#7CB342
  - 深绿色：#558B2F
  - 金黄色：#FDD835
  - 警告红：#E53935

#### 6. `static/js/script.js`
- **功能**：前端交互逻辑
- **包含**：
  - 文件上传处理
  - 拖拽上传
  - 文件夹加载
  - 图片导航
  - 预测触发
  - 结果显示
  - 快捷键支持
- **大小**：~10KB

### 文档文件

#### 7. `README.md`
- **功能**：项目完整说明文档
- **包含**：
  - 项目简介
  - 特性列表
  - 安装步骤
  - 使用说明
  - 技术架构
  - 注意事项
- **语言**：中文
- **大小**：~7KB

#### 8. `QUICKSTART.md`
- **功能**：快速入门指南
- **包含**：
  - 环境准备
  - 启动方法
  - 使用教程
  - 常见问题
  - 使用技巧
- **特点**：适合初学者，详细易懂
- **大小**：~8KB

#### 9. `SUGGESTIONS.md`
- **功能**：改进建议和扩展功能
- **包含**：
  - UI/UX 改进
  - 功能扩展
  - 技术优化

- **用途**：未来开发参考

#### 10. `config_example.py`
- **功能**：配置文件示例
- **包含**：
  - 配置项说明
  - 默认值设置
  - 使用示例
  - 常见问题解答
- **用途**：配置参考

### 辅助文件

#### 11. `.gitignore`
- **功能**：Git 版本控制忽略文件
- **包含**：
  - Python 缓存文件
  - 上传的临时文件
  - IDE 配置文件
  - 日志文件

#### 12. `uploads/.gitkeep`
- **功能**：保持上传目录存在
- **说明**：空目录不会被 Git 跟踪，需要占位文件

## 🎨 设计特点

### 视觉设计
- 🌾 **主题**：水稻田园风格
- 🎨 **配色**：绿色（健康）+ 金色（丰收）+ 红色（病害）
- ✨ **动画**：摇曳的水稻植株背景

### 交互设计
- 🖱️ **拖拽上传**：支持拖拽图片上传
