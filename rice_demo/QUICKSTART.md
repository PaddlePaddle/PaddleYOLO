# 🌾 快速开始指南 | Quick Start Guide

## 📋 准备工作

### 1. 检查环境
确保您已经安装了以下软件：
- ✅ Python 3.8 或更高版本
- ✅ PaddlePaddle 2.4 或更高版本
- ✅ 已训练好的模型文件

### 2. 找到您的模型文件

在项目中找到以下文件：

**配置文件**（在 `configs` 文件夹中）：
```
configs/yolov10/rice_blast_yolov10_n.yml
```

**权重文件**（在 `output` 文件夹中）：
```
output/rice_blast_yolov10_n/model_final.pdparams
```

记下这些文件的完整路径。

## 🚀 启动应用

### 方法一：使用批处理脚本（推荐，最简单）

1. 打开文件资源管理器，进入 `rice_demo` 文件夹
2. 双击 `run_app.bat` 文件
3. 等待程序启动
4. 浏览器会自动提示访问 http://127.0.0.1:5000

### 方法二：使用命令行

1. 打开命令提示符（CMD）
2. 切换到 rice_demo 目录：
```cmd
cd e:\projects\myPaddleYOLO\rice_demo
```

3. 运行以下命令：
```cmd
python app.py --config ../configs/yolov10/rice_blast_yolov10_n.yml --weights ../output/rice_blast_yolov10_n/model_final.pdparams
```

4. 看到 "Running on http://127.0.0.1:5000" 提示后，打开浏览器访问该地址

### 可选参数

**使用GPU加速**（推荐，速度更快）：
```cmd
python app.py --config [配置文件路径] --weights [权重文件路径] --use_gpu
```

**修改端口**（如果5000端口被占用）：
```cmd
python app.py --config [配置文件路径] --weights [权重文件路径] --port 8080
```

**允许局域网访问**（让其他电脑也能访问）：
```cmd
python app.py --config [配置文件路径] --weights [权重文件路径] --host 0.0.0.0
```

## 📖 使用教程

### 检测单张图片

1. 在Web界面中点击"上传图片"区域
2. 选择一张水稻叶片图片
3. 图片会显示在右侧预览区
4. （可选）调整"置信度阈值"滑块
5. 点击"开始检测"按钮
6. 等待几秒钟，查看检测结果

### 批量检测多张图片

1. 准备一个包含多张图片的文件夹，例如：
   ```
   e:\images\rice_samples
   ```

2. 在"加载文件夹"输入框中输入文件夹路径

3. 点击"加载"按钮

4. 系统显示找到的图片数量

5. 使用"上一张"/"下一张"按钮浏览图片
   - 💡 提示：也可以使用键盘的左右箭头键

6. 对每张图片点击"开始检测"查看结果

### 理解检测结果

检测完成后，您会看到：

**图片上的标记**：
- 🔴 红色方框：标出检测到的病斑位置
- 📝 标签：显示类别名称和置信度

**结果面板**：
- 📊 检测到病斑数量
- 📷 当前图片名称
- 📋 详细信息列表
  - 病害类型
  - 置信度百分比
  - 边界框坐标

## ⚙️ 调整检测参数

### 置信度阈值

位置：控制面板 → 检测设置

**什么是置信度阈值？**
- 模型对检测结果的"确信程度"
- 范围：0.0 到 1.0

**如何调整？**
- 🔼 **提高阈值**（例如 0.7）：
  - 只显示非常确定的病斑
  - 减少误报
  - 可能漏检一些病斑

- 🔽 **降低阈值**（例如 0.3）：
  - 显示更多可能的病斑
  - 提高检出率
  - 可能出现一些误报

**推荐设置**：
- 初学者：0.5（默认值）
- 保守检测：0.6-0.7
- 敏感检测：0.3-0.4

## 🎯 快捷键

在浏览器中使用以下快捷键：

- `→` 右箭头：下一张图片

## ❗ 常见问题

### 1. 程序无法启动

**可能原因**：
- Python未安装或版本太低
- 缺少必要的依赖包
- 配置文件或权重文件路径错误

**解决方法**：
```cmd
# 检查Python版本
python --version

# 安装依赖
pip install -r requirements.txt

# 检查文件是否存在
dir ..\configs\yolov10\rice_blast_yolov10_n.yml
dir ..\output\rice_blast_yolov10_n\model_final.pdparams
```

### 2. 浏览器无法访问

**可能原因**：
- 端口被占用
- 防火墙阻止

**解决方法**：
```cmd
# 尝试使用不同端口
python app.py --config [...] --weights [...] --port 8080

# 然后访问 http://127.0.0.1:8080
```

### 3. 检测速度很慢

**可能原因**：
- 使用CPU模式

**解决方法**：
```cmd
# 安装GPU版本（如果有NVIDIA显卡）
pip install paddlepaddle-gpu

# 使用GPU启动
python app.py --config [...] --weights [...] --use_gpu
```

### 4. 上传图片失败

**可能原因**：
- 图片格式不支持
- 图片文件太大（超过16MB）

**解决方法**：
- 使用 JPG、PNG、BMP 格式
- 压缩大图片后再上传

### 5. 检测结果不准确

**可能原因**：
- 图片质量问题
- 模型训练不足
- 置信度阈值设置不当

**解决方法**：
- 使用清晰的图片
- 调整置信度阈值
- 重新训练模型（如果需要）

## 💡 使用技巧

1. **批量处理**：
   - 将所有要检测的图片放在一个文件夹
   - 使用文件夹加载功能
   - 逐张检查效果

2. **保存结果**：
   - 使用浏览器的截图功能
   - 或右键点击图片 → 图片另存为

3. **对比检测**：
   - 调整不同的置信度阈值
   - 观察检测结果的变化
   - 找到最适合的参数

4. **快速浏览**：
   - 使用键盘左右箭头快速切换图片
   - 只对需要的图片进行检测
